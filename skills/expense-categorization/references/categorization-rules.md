# Reglas de imputación (borrador)

Tabla genérica de rubro → cuenta. Los nombres de cuenta deben coincidir con
el plan de cuentas de la empresa del sandbox; se ajustan al configurarlo.

| Rubro | Palabras clave / señales | Cuenta sugerida |
|---|---|---|
| Combustible | YPF, Shell, Axion, Puma, nafta, gasoil, GNC | Combustibles y movilidad |
| Peajes y estacionamiento | peaje, AUSA, estacionamiento, cochera | Combustibles y movilidad |
| Transporte | taxi, remis, Uber, Cabify, SUBE, colectivo, pasaje | Viáticos y movilidad |
| Comidas con clientes | restaurante, bar, "mesa", cubiertos, propina | Gastos de representación |
| Comidas del personal | almuerzo, viandas, delivery en horario laboral | Refrigerio y comidas del personal |
| Alojamiento | hotel, hostería, Booking, Airbnb | Viáticos y movilidad |
| Insumos de oficina | librería, resmas, tóner, papelería | Útiles y artículos de oficina |
| Supermercado | Carrefour, Coto, Día, La Anónima, limpieza, café | Gastos de limpieza y cafetería |
| Software y suscripciones | Google Workspace, Microsoft, Adobe, SaaS | Software y suscripciones |
| Telefonía e internet | Personal, Claro, Movistar, Telecentro, fibra | Telefonía e internet |
| Correo y envíos | Correo Argentino, OCA, Andreani, mensajería | Correo y envíos |

## Criterios de desempate

1. El historial del contador para el proveedor manda sobre esta tabla.
2. Si el recibo mezcla rubros (por ejemplo, supermercado con comida y limpieza), usar el rubro de mayor importe y mencionarlo en la justificación.
3. Si ninguna fila aplica con claridad, usar "Gastos generales" con confianza baja.
